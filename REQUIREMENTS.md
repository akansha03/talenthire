# Job Board API - Requirements

## User Stories
- As a company, I want to post job listings
- As a candidate, I want to search jobs
- As a candidate, I want to apply to jobs
- As a company, I want to see applicants

## Functional Requirements
- User authentication (JWT)
- Role-based access (company/candidate)
- Job CRUD operations
- Search with filters
- Application system
- Email notifications

## Non-Functional Requirements
- Response time < 200ms
- 70%+ test coverage
- Deployed with CI/CD
- Docker containerized
